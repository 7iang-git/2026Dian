# Level2: AlexNet 与 ResNet（CIFAR-10 图像分类）

在 Level1 CNN 的基础上，实现两个经典网络 AlexNet 和 ResNet，在 CIFAR-10 上训练并对比。

## 一、AlexNet（AlexNet.py）

### 1. 网络结构

沿用 2012 年原论文的层级设计，输入为 224x224 的 RGB 图：

| 层 | 配置 | 输出尺寸 |
| :--- | :--- | :--- |
| Conv1 | 3x64, kernel 11, stride 4, pad 2 | 64x56x56 |
| MaxPool | kernel 3, stride 2 | 64x27x27 |
| Conv2 | 64x192, kernel 5, pad 2 | 192x27x27 |
| MaxPool | kernel 3, stride 2 | 192x13x13 |
| Conv3 | 192x384, kernel 3, pad 1 | 384x13x13 |
| Conv4 | 384x256, kernel 3, pad 1 | 256x13x13 |
| Conv5 | 256x256, kernel 3, pad 1 | 256x13x13 |
| MaxPool | kernel 3, stride 2 | 256x6x6 |
| AdaptiveAvgPool | 输出 6x6 | 256x6x6 |
| FC1 | 9216 - 4096, Dropout 0.5 | 4096 |
| FC2 | 4096 - 4096, Dropout 0.5 | 4096 |
| FC3 | 4096 - 10 | 10 |

关键点：ReLU（解决深层网络的梯度消失）、Dropout 0.5（缓解全连接层过拟合）、
大数据集 + 数据增强（这是原论文能训起来的前提，这里用随机水平翻转做增强）。

## 二、ResNet（ResNet.py）

### 1. 网络结构

CIFAR 版 ResNet-18，由 BasicBlock 堆叠而成：

- BasicBlock：两层 3x3 卷积 + BatchNorm，输出与 shortcut 相加后再过 ReLU；
- 当 stride 不为 1 或通道数变化时，shortcut 用 1x1 卷积（带 BN）匹配维度；
- 主干 4 个 stage，每段 2 个 block，通道数 64-128-256-512；
- 与 224 输入的原版不同：第一层用 3x3 卷积、去掉最初的 MaxPool，
  让 32x32 的小图先保持分辨率，到 stage 里再逐级下采样。

特征图尺寸变化（输入 32x32）：

```
输入 3x32x32
conv1(3x3) -> 64x32x32
layer1(64)  -> 64x32x32
layer2(128) -> 128x16x16
layer3(256) -> 256x8x8
layer4(512) -> 512x4x4
GlobalAvgPool -> 512
FC -> 10
```

### 2. 残差连接的作用

普通网络堆深了之后，梯度在逐层回传时衰减，深层网络反而比浅层的训练误差更高（退化问题）。
残差结构让每一层只需要学习"相对输入的修正量"（F(x) = H(x) - x），最差情况下学成恒等映射即可，
梯度可以经 shortcut 直接回传，所以网络加深不再变差，反而能涨点。这是 ResNet 能 Scaling 的核心原因。

### 3. 超参数

| 超参数 | 值 |
| :--- | :--- |
| 数据集 | CIFAR-10（保持 32x32，不 Resize） |
| batch_size | 64 |
| 优化器 | Adam |

| epochs | 20 |
| 损失函数 | CrossEntropyLoss |
| 数据增强 | RandomHorizontalFlip + RandomCrop(32, padding=4) + Normalize |
| 权重保存 | my_resnet_cifar10.pth（按验证集准确率保存最优） |

## 四、对比分析（待实验后补充结论）

计划从这几个角度对比 AlexNet 与 ResNet：

1. **准确率**：ResNet 引入残差连接和 BatchNorm，同样数据下通常明显优于 AlexNet；
2. **收敛速度**：BatchNorm 让每层输入分布更稳定，可以用更大的学习率、收敛更快；
3. **加深的表现**：AlexNet 再加深会训不动（梯度消失/退化），ResNet 靠残差可以继续加深涨点；
4. **推理开销**：AlexNet 输入 224x224，全连接层参数占大头，ResNet 在 32x32 上算力开销小得多；
5. **归一化的影响**：AlexNet 原版只有局部响应归一化（这里没实现），ResNet 的 BN 是它好训的关键之一，
   对比时可以试着去掉 BN 验证。

## 五、核心知识点笔记

对应任务书 Level3 的核心知识点，把自己的理解整理如下。

### 1. AlexNet：深层 CNN、ReLU、Dropout 和数据增强

AlexNet 是 2012 年 ImageNet 竞赛冠军网络，它证明了"深一点的卷积网络 + 大数据 + GPU 训练"这条路是通的，
是深度学习在视觉领域爆发的起点。

- **深层 CNN**：5 个卷积层 + 3 个全连接层，比之前的 LeNet（2 个卷积层）深得多。
  层数深意味着特征逐级抽象：浅层学到边缘、颜色这类低级特征，深层组合出纹理、部件乃至物体级的特征。
  但当时没有 BN，网络一深梯度消失就冒头，AlexNet 能训起来靠的是下面两件事；
- **ReLU**：把 sigmoid/tanh 换成分段线性的 ReLU。ReLU 在正区间导数恒为 1，
  梯度回传时不会像 sigmoid（最大导数 0.25，多层连乘迅速衰减）那样层层缩小；
  计算上也只是一个 max，比指数运算便宜得多。这是深网络能收敛的关键之一；
- **Dropout**：训练时以 0.5 的概率随机丢弃全连接层的每个神经元，等效于每次迭代都在训练一个不同的子网络，
  测试时关闭，效果接近所有子网络的集成。全连接层参数多、最容易过拟合，Dropout 专门压制这一点；
- **数据增强**：原论文做了随机裁剪、水平翻转、颜色扰动，等于免费扩充了数据多样性。
  AlexNet 有 6000 万参数，没有大规模增强压不住过拟合。我训练时用了 RandomHorizontalFlip，
  ResNet 还加了 RandomCrop(32, padding=4)。

### 2. VGG：重复堆叠小卷积核与网络模块化

VGG（2014）的核心思想：把大卷积核换成连续堆叠的 3x3 小卷积核。

- **感受野等价，参数和深度双赢**：两层 3x3 串联的感受野等于一层 5x5，三层等于一层 7x7。
  但参数量从 25C^2 降到 18C^2，而且中间多了一次非线性，表达能力更强；
- **结构统一**：整个网络就是"卷积块（若干 3x3 卷积）+ MaxPool"重复堆叠，通道数每过一个池化翻倍
  （64-128-256-512），没有任何特殊组件。这种模块化让网络可以像搭积木一样按配置加深（VGG11/13/16/19），代码高度复用；
- **代价**：VGG 只堆深度不控制参数量，VGG16 约 1.38 亿参数（大头在全连接层），又大又慢。
  它证明了深度本身很重要，也把"怎么控制参数"这个问题留给了后面的网络；
- 结合 Level2 的思考：局部特征用小卷积核就够了（相邻像素关联），大范围依赖靠堆深度获得，
  没必要用大核一次算完——VGG 正是这个观点的实践。

### 3. ResNet：残差跳跃使得模型更适合 Scaling

- **退化问题**：实验发现网络加深到一定程度后训练误差反而上升。这不是过拟合（训练误差也高），
  而是优化变难了：深层网络很难学到接近恒等的映射，层数堆上去反而把前面学好的特征扰坏了；
- **残差连接**：让每个 block 学习 F(x) = H(x) - x，输出为 F(x) + x。
  最差情况下把 F(x) 学成 0，block 就是恒等映射，加深至少不会变差；
  需要的特征修正在此基础上叠加即可，把"学目标映射"变成"学残差修正"，优化目标简单得多；
- **梯度高速公路**：反向传播时梯度可以直接沿 shortcut 跳过若干层回传，连乘路径缩短，深网络梯度不消失。
  配合 BatchNorm，ResNet 可以堆到上百层还能涨点；
- **对 Scaling 的意义**：模型能力随深度平滑增长、训练稳定，才有 ResNet-50/101/152 这类更大规模的缩放。
  今天 Transformer 里的残差连接，源头都在这里；
- 实现细节见上文 ResNet 一节：维度不匹配时 shortcut 用 1x1 卷积对齐。

### 4. U-Net：编码器、解码器、下采样、上采样和跳跃连接

U-Net（2015）是分割/像素级还原任务的标准骨干，Level4 的手写擦除用的就是它。

- **编码器（下采样路径）**：反复"卷积块 + 下采样"，特征图越变越小、通道越变越多，
  压缩空间信息、积累语义信息——深层的特征知道"这里是什么"；
- **解码器（上采样路径）**：把特征图逐级放大回原尺寸、通道逐级减少，
  把语义信息还原到每个像素上——逐像素任务需要回答"每个位置是什么"；
- **下采样/上采样的取舍**：下采样让小图上算大感受野变得便宜，但空间细节永久丢失；
  上采样（转置卷积或插值）只能恢复分辨率，恢复不了丢掉的细节；
- **跳跃连接**：把编码器同分辨率的特征图在通道维拼接到解码器对应层，高分辨率细节直接跨过瓶颈传给解码器。
  编码器负责"看得懂"，跳跃连接负责"看得清"。注意与 ResNet 的区别：U-Net 是拼接（concat），
  ResNet 是逐元素相加（add）；
- **和分类网络的本质区别**：分类网络最后把空间压成一个向量，U-Net 保持并重建空间结构。
  手写擦除是逐像素还原任务，所以 Level4 选 U-Net：印刷文字的边缘细节靠跳跃连接保住，
  手写内容的擦除靠编码器的语义理解完成。
