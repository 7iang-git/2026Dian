## 一、网络结构

text

```
输入: [batch, 1, 28, 28]
↓ view 展平
[batch, 784]

FC1: Linear(784 → 64)
ReLU

FC2: Linear(64 → 64)
ReLU

FC3: Linear(64 → 64)
ReLU

FC4: Linear(64 → 10)
log_softmax(dim=1)

输出: [batch, 10] 的 log 概率
```



具体结构：

| 层   | 类型   | 输入维度 | 输出维度 | 激活函数    |
| :--- | :----- | :------- | :------- | :---------- |
| 输入 | 展平   | 1×28×28  | 784      | 无          |
| fc1  | 全连接 | 784      | 64       | ReLU        |
| fc2  | 全连接 | 64       | 64       | ReLU        |
| fc3  | 全连接 | 64       | 64       | ReLU        |
| fc4  | 全连接 | 64       | 10       | log_softmax |

可学习参数量大约是：

text

```
fc1: 784×64 + 64 = 50,240
fc2: 64×64 + 64  = 4,160
fc3: 64×64 + 64  = 4,160
fc4: 64×10 + 10  = 650
总计约 59,210 个参数
```



## 二、超参数

代码中显式设置或隐含使用的超参数如下：

### 1. 网络结构超参数

| 超参数         | 值          |
| :------------- | :---------- |
| 输入维度       | 784         |
| 隐藏层数       | 3           |
| 每层隐藏单元数 | 64          |
| 输出类别数     | 10          |
| 隐藏层激活函数 | ReLU        |
| 输出层激活函数 | log_softmax |
| 网络类型       | 全连接 MLP  |

### 2. 优化相关超参数

| 超参数       | 值                |
| :----------- | :---------------- |
| 优化器       | Adam              |
| 学习率 lr    | 0.001             |
| Adam betas   | 默认 (0.9, 0.999) |
| Adam eps     | 默认 1e-8         |
| weight_decay | 未设置，默认 0    |
| 学习率调度   | 无                |
| 梯度裁剪     | 无                |

### 3. 训练相关超参数

| 超参数       | 值           |
| :----------- | :----------- |
| batch_size   | 64           |
| shuffle      | True         |
| epochs       | 10           |
| 损失函数     | `nll_loss`   |
| 训练集       | MNIST 训练集 |
| 测试集       | MNIST 测试集 |
| 每轮是否评估 | 是           |
| 早停         | 无           |
| 随机种子     | 未设置       |

### 4. 数据预处理

| 项目      | 值                   |
| :-------- | :------------------- |
| transform | `ToTensor()`         |
| 归一化    | 只把像素缩放到 [0,1] |
| 数据增强  | 无                   |
| 标准化    | 无                   |
